## 실행 방법

1. 노트북을 열고 **Colab에서 열기**를 누릅니다.
2. Colab 왼쪽 🔑(보안 비밀)에 `OPENAI_API_KEY`를 등록하고 노트북 액세스를 켭니다.
3. 위에서부터 순서대로 실행합니다.
